Satisfactory-sync

Installation instructions

0.)

Backup you saves in case something goes wrong

1.)

Download Rclone

2.)

Setup a cloud service of your choice using a guide on Rclone's site, the only requirement is to name the drive "satisfactory".

  • Tip: You can open a command prompt in the current folder by typing "cmd" into the address bar in the file explorer.)
  • Google drive setup guide: https://rclone.org/drive/
  • I recommend creating a new account just for this purpose.

3.)

Open the .bat file and replace `[ID]` with your store's ID. There's a random [guide](https://www.ubisoft.com/en-gb/help/account/article/finding-your-steam-id/000060565).

4.)

Disabling of cloud saves in your store's launcher is recommended to avoid mixing of your and your friend's saves.

5.)

All your friends have to do that with the same cloud account.

Note:

  • If you all want to play at the same time, only one player needs to run the script. (It won't even allow more people to run it at the same time).
  • First time running this, it will throw an error - just ignore it.
  • Never close the command prompt window manually.
